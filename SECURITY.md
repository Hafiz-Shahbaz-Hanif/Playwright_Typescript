# Security policy

This is a portfolio test-automation framework. It runs against public demo
applications (Practice Software Testing / "The Toolshop", restful-booker) and
contains no proprietary code, production credentials, or customer data — the
values in `env/config.ts` and `.env.example` are those demos' own published
test accounts.

## Reporting a vulnerability

If you find a real security issue in this repository itself (for example, a
dependency with a known CVE, or a way this code could be misused against a
target it wasn't written for), please open a
[GitHub issue](https://github.com/Hafiz-Shahbaz-Hanif/Playwright_Typescript/issues/new)
or email **shahbazhanif87@gmail.com**. There is no bug bounty; this is a
demonstration project, but reports are still welcome and will be looked at.

Please do not open public issues about vulnerabilities in **Practice Software
Testing** or **restful-booker** themselves — those are third-party
applications not maintained here.

## Supported versions

This repository tracks `main` only; there are no maintained release branches.
